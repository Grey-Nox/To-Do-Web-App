# 📝 Django To-Do Web App

A robust, backend-driven To-Do web application built with Python and Django. This project features user authentication and full task management capabilities, allowing users to securely create, manage, and delete their daily tasks.

![Django](https://img.shields.io/badge/django-%23092E20.svg?style=for-the-badge&logo=django&logoColor=white)
![SQLite](https://img.shields.io/badge/sqlite-%2307405e.svg?style=for-the-badge&logo=sqlite&logoColor=white)

---

## 🌟 Features

*   **User Authentication:** Secure Sign Up, Login, and Logout functionality.
*   **Task Management:** Users can add tasks, view them on their dashboard, and delete them when completed.
*   **Django Admin Panel:** Fully integrated admin panel to manage users and the `TODO` model out of the box.
*   **Model-View-Template (MVT) Architecture:** Clean separation of logic, database routing, and UI.

---

## 🛠️ Tech Stack

*   **Backend:** Python, Django 3.2+
*   **Database:** SQLite (Django Default) 
*   **Frontend:** HTML, CSS, Django Templates
